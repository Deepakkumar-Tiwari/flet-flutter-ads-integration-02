# flet-ads-ext
FletAdsExt control for Flet

## Installation

Add dependency to `pyproject.toml` of your Flet app:

* **Git dependency**

Link to git repository:
d
```
dependencies = [
  "flet-ads-ext @ git+https://github.com/MyGithubAccount/flet-ads-ext",
  "flet>=0.80.3",
]
```

* **uv/pip dependency**  

If the package is published on pypi.org:

```
dependencies = [
  "flet-ads-ext",
  "flet>=0.80.3",
]
```

Build your app:
```
flet build macos -v
```
